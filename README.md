# 坦克大战 · Tank Battle

一个用纯 HTML + Canvas + JavaScript 写成的「坦克大战」小游戏，单文件即可运行，无需任何依赖。

## 玩法

守住底部中央的基地（HQ），消灭每一关来犯的敌方坦克。

- **移动**：`W A S D` 或方向键
- **射击**：空格键
- **目标**：基地被摧毁或生命耗尽则游戏结束；清空当关全部敌军进入下一关

## 地形与机制

| 地形 | 说明 |
| --- | --- |
| 砖墙 | 可被子弹击毁（两发，先裂缝后摧毁） |
| 钢墙 | 无法摧毁 |
| 水域 | 坦克不可通过，子弹可飞过 |
| 树林 | 可通行并遮挡坦克，可用来伏击敌人 |

- 敌军有三种类型：普通 / 快速 / 装甲（两格血），越到后期越强。
- 玩家与敌方子弹会互相抵消。
- 每关敌军数量与强度递增，共 3 张地图循环推进。

## 本地运行

直接双击 `index.html` 用浏览器打开即可，或：

```bash
# 任意一个静态服务器，例如 Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```
